# Risks and Ethics: Social Media Data Analysis

| Risk | Mitigation |
|---|---|
| Small or biased sample | State sample size and limitations in the report. |
| Confusing correlation with causation | Use cautious wording; suggest A/B tests. |
| Privacy and platform terms | Use public or own data only; anonymise usernames. |

## Ethics and responsible-use notes
- Be honest about limitations in the README and report; do not overstate accuracy.
- Use only data you are allowed to use; anonymise any personal information.
- Document who could be harmed by a wrong output and how the design reduces that risk.
